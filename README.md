# 💇🏾‍♀️✨ Loc Me In

**Natural-hair studio website with service selection, appointment-request planning, hair-care guidance, a lookbook, and a personal client planning interface.**

🏷️ Maintained in [qamotech/lmi](https://github.com/qamotech/lmi) · 🌐 Public repository

## ✨ What is here

- 💇 Service menu and style configuration.
- 📅 Appointment-request planner and preparation guidance.
- 🎨 Style concierge, budget navigator, maintenance timeline, and lookbook.
- 📍 Location, map, portfolio, and contact sections.

## 🧭 Try the project

Explore the service menu, build a sample style plan, review appointment preparation, and verify the contact/request handoff before publishing changes.

## 🚀 Local setup

```sh
git clone https://github.com/qamotech/lmi.git
cd lmi
```

Use a current browser. Serve the repository root to preserve relative assets and a stable browser origin:

```sh
python -m http.server 8000
```

Open `http://localhost:8000/index.html`. Keep related assets beside the entry file. No npm setup is declared in the inspected repository.

## ⚙️ Configuration & data

A request planner is not a confirmed booking system. Verify prices, address, availability, reviews, and service claims with the owner. External maps and fonts contact third-party services.

Keep credentials, private exports, customer records, and personal information out of commits and screenshots. A local browser demo is not evidence of account security, reliable persistence, or connected external services. Preserve exports before changing storage keys or resetting an application.
